# ระบบค้นหาและกรองเมนู — Design (ฉบับสั้น, อนุมัติแล้ว)

ไฟล์เป้าหมาย: `thai-food.html` (ไม่มี `index.html` ในโฟลเดอร์; ผู้ใช้ยืนยันแนวทางนี้)

## Intent
ให้ผู้ใช้หาเมนูได้เร็วขึ้นและกรองได้ละเอียดขึ้น นอกเหนือจากการกรองตามหมวดที่มีอยู่

## Goals
- ช่องค้นหา: ชื่อไทย, ชื่ออังกฤษ, คำอธิบาย; ไม่สนตัวพิมพ์เล็กใหญ่; ปุ่ม ✕ ล้างคำค้น
- ตัวกรองระดับความเผ็ด (ทั้งหมด / ไม่เผ็ด / 🌶 / 🌶🌶 / 🌶🌶🌶)
- ตัวกรองภาค (ทั้งหมด / ภาคกลาง / ภาคอีสาน / ภาคใต้ / ทั่วไทย)
- ทุกตัวกรองรวมกันแบบ "และ" กับหมวด/เมนูโปรดเดิม
- แสดงจำนวนเมนูที่พบ; ถ้าไม่พบเลยแสดงข้อความ + ปุ่มล้างตัวกรอง
- ปุ่มสุ่มเมนูสุ่มจากผลที่กรองแล้ว (ผ่าน `isVisible()` เดิม)

## Non-goals
- ไม่เพิ่มไลบรารี, ไม่แยกไฟล์, ไม่เปลี่ยนโครงข้อมูลเมนู, ไม่เก็บคำค้นใน localStorage

## Constraints
- ใช้คำตาม GLOSSARY.md (เมนู, หมวด, เมนูโปรด)
- สร้าง DOM ด้วย textContent เท่านั้น (ไม่ inject HTML) ตามโค้ดเดิม
- รองรับมือถือ, dark mode, เข้าถึงได้ (label, aria-live, focus-visible)

## Approaches
1. แก้ไฟล์เดียว ขยาย `isVisible()` ให้รวมเงื่อนไขทั้งหมด (เลือก — ปุ่มสุ่มและการแสดงผลใช้ร่วมกันโดยไม่ต้องแก้เพิ่ม)
2. แยกโมดูล/ไฟล์ JS — เกินความจำเป็นสำหรับหน้าเดียว
3. ใช้ไลบรารีค้นหา fuzzy — เกินจำเป็น ข้อมูลมีแค่ 12 เมนู

## Left to the builder
รายละเอียด UI (ใช้ select หรือชิป สำหรับความเผ็ด/ภาค), ข้อความ empty state, การจัดวางบนมือถือ
